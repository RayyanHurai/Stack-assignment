# Stack-Based Expression Evaluator

## Description
A Python program that reads mathematical expressions from `input.txt`,
evaluates each one using a stack, and writes the results to `output.txt`.

## Files
- `main.py` - source code
- `input.txt` - sample input
- `output.txt` - output generated by the program
- `README.md` - this file

## How to Run
1. Install Python 3.8 or newer.
2. Put all files in the same folder.
3. Open a terminal in that folder.
4. Run: `python main.py` (or `py main.py` on Windows)
5. Open `output.txt` to see the results.

## Input Format
- One expression per line.
- Expressions are separated by a line containing only dashes (`-----`).
- Supported: `+ - * /`, parentheses, decimal numbers, negative numbers.

Example:

    3 + 5 * 2
    -----
    (8 / 4) + 7 * 2
    -----
    10 - (2 + 3) * 4

## Output Format
- Each expression is replaced by its result, in the same line position.
- The same `-----` separators are kept.

Example:

    13
    -----
    16
    -----
    -10

## Assumptions and Limitations
- Expressions are written in normal (infix) notation.
- Only the operators `+ - * /` are supported (no powers or functions).
- Whole-number results print without ".0" (for example 13, not 13.0).
- Decimal results are rounded to 4 places.
- Division by zero or an invalid expression prints an "Error: ..." line
  instead of stopping the program.
- Blank lines in the input are ignored.
- The file names `input.txt` and `output.txt` are fixed in the code and
  must be in the same folder as `main.py`.
